---

3/

What is UrchinLoop exactly?

It's a single JavaScript file. Drop it into any project — browser extensions, Telegram bots, CLIs, servers, whatever.

It gives you:
→ Multi-step reasoning (up to 24 chained tool calls)
→ 7-layer persistent memory
→ Self-learning skills that evolve over time
→ Goal decomposition for complex tasks
→ Pluggable LLM (OpenAI, Anthropic, local models)
→ Pluggable storage (in-memory, Redis, SQLite, anything)

---

4/

Building your own tool takes 5 lines:

const { urchinLoop, createMemoryStorage } = require('./urchinloop.js');

const result = await urchinLoop('Analyze this data', {
  storage: createMemoryStorage(),
  callLLM: yourLLMFunction,
  tools: {
    MY_TOOL: async (param) => { /* your logic */ }
  }
});

That's it. Your tool now has memory, reasoning, and chain-of-thought — for free.
